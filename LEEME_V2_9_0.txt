BIA HONDURAS - PWA v2.9.0 · DISTRIBUCIÓN REFERENCIA

OBJETIVO
Replicar en la aplicación real la distribución visual aprobada, aprovechando al máximo el espacio disponible tanto en web como en Android.

CAMBIOS PRINCIPALES
- Contenido web utiliza prácticamente el 100% del ancho disponible.
- Se creó una estructura independiente para el panel lateral.
- Excel, Metas y Resumen del día ya no fuerzan la altura de Preparación/Actividades.
- Los historiales aparecen inmediatamente debajo del área operativa.
- En proceso ahora admite 1, 2, 3 o más procesos en una cuadrícula automática.
- En móvil los procesos activos se recorren horizontalmente como tarjetas.
- Preparación y Actividades se ajustan a su contenido sin alturas vacías.
- Metas tiene un resumen compacto con barras de cumplimiento.
- Cierre diario permanece disponible debajo del tablero ejecutivo.
- Se mantienen Supabase, permisos, Excel, ausencias, auditoría y gestión de equipo.

BASE DE DATOS
No requiere SQL adicional si v2.6.5 ya funciona correctamente.

INSTALACIÓN
1. Reemplazar TODOS los archivos publicados por los de v2.9.0.
2. Ctrl+F5 en web.
3. En Android cerrar totalmente la PWA.
4. Si conserva CSS anterior, borrar caché o reinstalar la PWA.
