CONTROL DE TIEMPOS BIA - INSTALACIÓN

ARCHIVOS
- index.html: inicio de sesión.
- cronometros.html: aplicación.
- cronometros.js: lógica, Realtime y llamadas RPC.
- supabase-config.js: conexión del proyecto existente.
- instalacion_segura_supabase.sql: tablas, RLS y funciones atómicas.

PASOS
1. En Supabase, abra SQL Editor.
2. Ejecute instalacion_segura_supabase.sql.
3. En Authentication > Users, confirme que los usuarios tengan correo y contraseña.
4. Suba los cuatro archivos web al mismo directorio de GitHub Pages.
5. Ingrese mediante index.html.

CONTROL DE DUPLICADOS
- Solo puede existir un cronómetro activo por empleado y categoría.
- Cada cambio exige la versión exacta del registro.
- La función SQL bloquea la fila antes de modificarla.
- El historial tiene timer_id UNIQUE.
- El primer cierre válido se guarda; cualquier segundo intento recibe conflicto.
- Realtime actualiza los demás dispositivos.
