BIA HONDURAS - PWA v2.9.6

NUEVAS PÁGINAS
- cronometros.html = Principal
- cba.html = CBA
- src.html = SRC

NAVEGACIÓN
En el encabezado se agregó un selector Principal / CBA / SRC. La sesión de Supabase se mantiene al cambiar de página.

PWA
El Service Worker almacena también CBA y SRC y el manifiesto incluye accesos directos para ambas páginas.

IMPORTANTE
Esta versión crea las páginas adicionales con la misma funcionalidad y la misma conexión actual a Supabase. Los datos operativos siguen compartiendo la misma base de datos.

Si posteriormente se desea que CBA y SRC tengan inventarios/colaboradores/cronómetros totalmente separados, se puede agregar un campo de agencia en la base de datos y filtrar cada página por su agencia.

INSTALACIÓN
1. No requiere SQL adicional.
2. Reemplazar todos los archivos publicados por este paquete.
3. Ctrl + F5 en web.
4. En Android cerrar/reabrir la PWA o borrar caché si conserva la versión anterior.
