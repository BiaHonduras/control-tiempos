PWA CONTROL DE TIEMPOS BIA – INSTALACIÓN EN ANDROID

1. EJECUTE LA BASE DE DATOS
   En Supabase > SQL Editor ejecute instalacion_segura_supabase.sql.

2. PUBLIQUE POR HTTPS
   Suba todos los archivos y la carpeta icons al mismo directorio de GitHub Pages.
   Una PWA no funciona correctamente con file:// ni abriendo el HTML por doble clic.

3. PRUEBE LA RUTA
   Ejemplo: https://biahonduras.github.io/proyecto-cronometros/

4. INSTÁLELA EN ANDROID
   - Abra la dirección en Google Chrome.
   - Inicie sesión.
   - Pulse “Instalar app” o el menú ⋮ > Instalar aplicación.
   - Android creará un icono y la abrirá sin barra del navegador.

COMPORTAMIENTO SIN INTERNET
- La interfaz y los archivos básicos pueden abrirse desde caché.
- Las acciones de cronómetro quedan deshabilitadas sin internet.
- No se crean colas locales de acciones, porque Supabase debe ser la autoridad y validar versiones.
- Al recuperar internet, Realtime vuelve a sincronizar la información.

ARCHIVOS PWA
- manifest.webmanifest: nombre, iconos, modo standalone.
- service-worker.js: caché de la interfaz.
- pwa.js: instalación, estado de red y actualizaciones.
- offline.html: pantalla sin conexión.
- icons/: iconos para Android.

PARA GENERAR UN APK/AAB
Después de publicar y verificar la PWA, puede envolverse como Trusted Web Activity usando PWABuilder o Bubblewrap. Para Play Store también se necesita Digital Asset Links y firma de Android. La PWA instalada desde Chrome no necesita APK.
