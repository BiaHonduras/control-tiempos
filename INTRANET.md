# Intranet BIA Honduras

Entrada: https://biahonduras.github.io/control-tiempos/intranet.html

Inicia sesión con tu cuenta habitual de Control de Tiempos. Desde la pantalla principal puedes abrir Control de Tiempos, Control de Contenedores y Control de Devoluciones.

La sesión se comparte al utilizar el mismo navegador y el mismo dominio. Cada aplicación mantiene los permisos de tu cuenta y tus sedes. Una sesión cerrada o vencida requiere ingresar nuevamente.

Usa el enlace Intranet para volver al menú principal. El portal incluye el logo de BIA Honduras y un listado de aplicaciones que puede ampliarse en futuras actualizaciones.
